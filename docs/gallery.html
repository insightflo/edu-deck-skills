스킬이 조립에 쓰는 재료 전부 — 리소스팩 설계 8종·흐름 8종(64조합 빌드 검증), 장 배치 36계열 186변형, 테마 8종, 모션 시그니처 30종 + 공통 기법 5종. 모두 실제 빌드 파이프라인으로 렌더한 실물 캡처다.

리소스팩 64장 배치 194테마 8 모션 36▶ 배치 전체 덱(194장 열람)

리소스팩 — 설계 8종 × 학습 흐름 8종

눈에 보이는 다양함은 설계가 만든다 — 워크북의 마주본 면, 사례철의 기록A/B, 잡지의 편집 지면처럼 배치 문법 자체가 다르다. 흐름은 수업의 뼈대(단계 구성·문안)를 바꾼다. 8×8=64조합을 전수 빌드·검사했다(64/64 PASS).

학습 흐름 8종 — 실제 예시 덱 8개 (주제 동일: 「영양 성분표 읽기」)

같은 주제·같은 casebook 설계로 흐름만 바꿔 실제로 조립한 덱 8개다 — 흐름은 단계 수·순서·문안(수업의 뼈대)을 바꾼다. 카드를 누르면 크게 볼 수 있다.

장 배치 조각 — 37계열 194변형

legacy 경로의 배치 사전. 조각은 지시가 아니라 재료다 — 자유 모드에서는 이걸 넘어서 직접 배치를 설계해도 된다. 194장 전체를 슬라이드로 넘겨 보려면 위의 ▶ 배치 전체 덱.

테마 8종 — 같은 덱 × 전 테마 매트릭스

같은 주제의 표지·목차·내용 장 3개를 테마 8종으로 각각 조립한 실물이다 — 한 줄이 한 테마. 테마는 색·그림자·반경을 바꾼다(배치 문법은 그대로). 아래는 같은 장면(타일 그리드)의 단일 비교.

모션 시그니처 — 31종 전체 + 공통 기법 5종

계열마다 실행 이름이 자동 배정된다(37계열이 31개 이름을 공유·재사용 — stack-reveal은 구성도 부품이 직접 기록). 퀴즈 판정은 실제 클릭까지 녹화했다. 인쇄·자습·reduced-motion 에서는 항상 최종 상태가 그대로 보인다.

공통 기법 5종 — 실행 이름 위에 얹히는 조형 어휘 (data-fx)

계열 시그니처와 별개로 조각이 data-fx 로 옵트인하는 기법이다. 인쇄·정적 상태는 기법 없을 때와 픽셀 차이 0(검증 완료).
