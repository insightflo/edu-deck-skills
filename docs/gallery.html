눈에 보이는 다양함은 설계가 만든다 — 워크북의 마주본 면, 사례철의 기록A/B, 잡지의 편집 지면처럼 배치 문법 자체가 다르다. 흐름은 수업의 뼈대(단계 구성·문안)를 바꾼다. 8×8=64조합을 전수 빌드·검사했다(64/64 PASS).

사례 판단 case — 5단계

  1. 결말을 가린 사례를 읽습니다
  2. 확인된 사실·추정·미확인을 나눕니다
  3. 새 단서가 처음 판단을 바꾸나요?
  4. 결과와 판단 과정을 따로 검토합니다
  5. 조건이 달라진 사례를 다시 판단합니다

비교 선택 compare — 4단계

  1. 보기 전에 목적과 제약을 정합니다
  2. 동일한 기준으로 대안을 살핍니다
  3. 무엇을 얻고 무엇을 포기하는지 봅니다
  4. 제약이 다른 상황에서 다시 고릅니다

같은 casebook 설계 — 단계 수·순서·문안이 흐름마다 다르고, 배치 문법은 설계가 정한다.
