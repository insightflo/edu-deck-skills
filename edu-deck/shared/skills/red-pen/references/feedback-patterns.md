# 피드백 패턴 모음

Red-Pen 스킬에서 사용하는 편집장 K 스타일 피드백 패턴입니다. 16가지 교정 기준을 적용할 때 실제로 전달하는 멘트 모음입니다.

---

## 1. 긍정 피드백 패턴

### 구조가 탁월할 때 (Bone)
- "**두괄식 완벽.** 첫 문장이 문단 전체를 지배하고 있네요."
- "**논리 흐름이 물 흐르듯.** A→B→C 연결이 자연스럽습니다."
- "**팩트가 단단합니다.** 모든 주장에 출처가 붙어 있어 신뢰가 갑니다."
- "**일관성 유지 완벽.** 처음부터 끝까지 같은 톤, 같은 시제. 프로페셔널합니다."

### 표현이 뛰어날 때 (Flesh)
- "**이 비유, 훔치고 싶네요.** [인용]... 참신하면서도 정확합니다."
- "**문장 리듬이 살아있습니다.** '짧다. 길게 흐른다. 다시 짧다.' 이 호흡 좋습니다."
- "**Show Don't Tell 완벽 구현.** '화났다'가 아니라 '주먹을 쥐었다'로 보여주는 센스."
- "**삭제의 용기.** 불필요한 설명을 과감히 생략했네요. 이게 진짜 실력입니다."

### 감성이 훌륭할 때 (Soul)
- "**이 여운, 며칠 남을 것 같네요.** 마지막 문장이 계속 맴돕니다."
- "**진정성이 느껴집니다.** 당신이 이 주제를 진심으로 고민했다는 게 전해집니다."
- "**감정선이 절제되어 더 강렬합니다.** 오버하지 않고 정확한 지점에서 멈췄네요."

### 구체적 강점 지적 방법
```
[인용구] + [칭찬] + [이유]

예시:
"프로젝트를 완료했다"를 "밤을 새워 드디어 완료했다"로 바꾼 부분,
탁월합니다. '밤을 새워'와 '드디어' 두 단어로 과정과 감정을
동시에 전달했네요.
```

## 2. 개선 피드백 패턴

### Bone (구조) 문제 지적

#### 명사 과용
- "**'-의' 지옥에서 탈출하세요.** '개선의 실행' → '개선하다'로 동사를 살리면 문장이 숨을 쉽니다."
- "**명사로 매몰차게 끝내지 마세요.** '노력의 지속' → '계속 노력하다'. 동사가 글에 생명을 불어넣습니다."

#### 두괄식 부재
- "**핵심이 3문단에 숨어있네요.** 독자는 그 전에 이미 떠났을 겁니다. 첫 문장으로 올리세요."
- "**기승전결은 소설에서나 쓰세요.** 실용문은 결론부터. 결기승전 구조로 전환하세요."

#### 팩트 오류
- "**'대부분'은 몇 퍼센트죠?** 애매한 표현은 신뢰를 떨어뜨립니다. 구체적 수치를 제시하세요."
- "**'연구에 따르면'은 어떤 연구?** 출처 없는 인용은 루머와 다를 바 없습니다."

#### 논리 비약
- "**A에서 Z로 순간이동했네요.** B~Y 과정이 없으면 독자는 못 따라갑니다. 징검다리를 놓으세요."
- "**'따라서'를 붙인다고 논리가 되는 게 아닙니다.** 인과관계를 증명하세요."

#### 일관성 부재
- "**'나'였다가 '우리'였다가 정신없네요.** 주어 하나만 선택하세요."
- "**과거-현재-미래를 자유롭게 넘나드네요.** 시제 통일하세요. 지금은 타임머신이 아닙니다."

### Flesh (표현) 문제 지적

#### 형용사/부사 남용
- "**'매우 놀라운 엄청난'... 과잉이 오히려 약해 보입니다.** '3배 증가'라는 팩트가 더 강력합니다."
- "**형용사는 구체적 명사의 적.** '좋은 결과' → '20% 증가'. 수치로 말하세요."

#### SDT 위반
- "**'화가 났다'고 설명하지 말고 화난 모습을 보여주세요.** '책상을 쳤다', '목소리를 높였다'."
- "**Tell이 아니라 Show.** 감정어를 행동으로 전환하세요."

#### 비유 과잉/부족
- "**비유 과다 복용.** 문장마다 비유하면 독자가 피곤합니다. 핵심에만 쓰세요."
- "**딱딱한 나열만.** 비유 하나면 이 개념이 훨씬 쉬워질 텐데요."
- "**이 비유, 1990년대에서 왔나요?** '디지털 시대의 횃불'은 이제 진부합니다."

#### TMI
- "**'2023년 1월 3일 월요일 오전 9시 32분'... TMI입니다.** '올해 초'로 충분합니다."
- "**배경 설명이 본문보다 길면 문제입니다.** 핵심을 먼저, 배경은 필요한 만큼만."

#### 리듬 부재
- "**긴 문장만 이어지니 숨이 막힙니다.** 짧은 문장으로 호흡을 주세요."
- "**짧은 문장만. 반복. 단조롭네요.** 길이를 변주해서 리듬을 살리세요."

#### 번역체
- "**'~에 의해'는 영어의 망령입니다.** 능동형으로 바꾸세요."
- "**'되어지다'는 피동의 피동.** 이중 피동은 한국어의 적입니다."
- "**'~적', '~화'가 넘쳐나네요.** '효율적' → '효율 높은', '최적화' → '최적으로 만들다'."

#### 접속사 과다
- "**'그리고'를 4번 연속...** 접속사 없이도 문장은 연결됩니다. 삭제하세요."
- "**접속사는 약자의 도구입니다.** 강한 문장은 접속사 없이도 흐릅니다."

### Soul (영혼) 문제 지적

#### 감정 미흡
- "**로봇이 쓴 글 같네요.** 당신의 감정은 어디 있나요? 진정성을 담으세요."
- "**프로젝트 완료가 그저 사실 나열인가요?** '밤새 싸웠다', '드디어 해냈다' 같은 감정을 드러내세요."

#### 여운 부족
- "**'이상입니다'로 끝내면 여운도 끝입니다.** 독자에게 생각할 여지를 남기세요."
- "**모든 걸 설명하려 들지 마세요.** 여백이 있어야 독자가 상상합니다."

#### 어휘 빈곤
- "**'좋은'을 7번 썼네요.** 긍정적, 효과적, 현명한... 동의어 사전 펼치세요."
- "**같은 단어 반복은 어휘력 부족의 증거입니다.** 다양한 표현을 찾으세요."

#### 삭제 대상
- "**'~하는 것', '~라고 할 수 있다'... 군더더기입니다.** 삭제해도 의미 변화 없습니다."
- "**이 문단, 없어도 논리 안 깨집니다.** 용기 내서 지우세요. 글은 덜어낼수록 강해집니다."

## 3. 편집장 K 스타일 피드백 모음

### 날카롭지만 건설적인 멘트

#### 구조 문제
- "독자는 당신의 사고 과정을 추적할 의무가 없습니다. 결론부터 던지세요."
- "팩트 없는 주장은 의견일 뿐입니다. 출처를 붙이거나 삭제하세요."
- "논리 비약으로 독자를 낙오시키고 있습니다. 단계를 밟으세요."

#### 표현 문제
- "형용사 세 개를 붙인다고 강조가 되는 게 아닙니다. 하나의 정확한 동사가 낫습니다."
- "비유는 칼입니다. 정확하면 명쾌, 부정확하면 혼란. 지금은 후자."
- "번역체가 글의 50%를 차지하고 있네요. 한국어로 다시 쓰세요."

#### 감성 문제
- "이 글에서 당신을 찾을 수가 없습니다. 어디 있나요?"
- "여운 없는 마무리는 뒷맛 없는 요리와 같습니다."
- "삭제가 두렵나요? 글쓰기의 80%는 지우기입니다."

### 상황별 피드백 예시

#### 전체적으로 좋을 때
"**85점.** Bone 탄탄, Flesh 매끄러움. Soul에서 5점 깎였습니다. 마지막 여운만 보완하면 출간 가능."

#### 중간 정도일 때
"**60점.** 논리는 있는데 표현이 발목을 잡네요. 번역체와 형용사 남용부터 고치세요."

#### 근본적 수정 필요할 때
"**40점. 처음부터 다시.** 두괄식 구조로 재설계하고, 팩트를 보강하고, 문장 하나하나 능동형으로 재작성하세요. 지금 상태로는 공개 불가입니다."

#### 특정 부분만 문제일 때
"**전반부 90점, 후반부 50점.** 2/3 지점에서 집중력을 잃었네요. 3문단부터 다시 보세요."

## 4. 피드백 강도 조절

### 초보 작성자용 (부드럽게)

**원칙**: 격려 + 구체적 대안 + 작은 성공 경험

#### 예시
- "**좋은 시도입니다.** 다만 '개선의 실행'을 '개선하다'로 바꾸면 더 힘 있는 문장이 됩니다. 한번 고쳐볼까요?"
- "**이 비유 괜찮네요.** 다만 '디지털 시대의 횃불'보다 '어둠 속 네비게이션' 같은 현대적 비유는 어떨까요?"
- "**첫 문장 잘 썼습니다.** 이제 이 문장을 문단 맨 앞으로 옮겨보세요. 훨씬 명확해질 겁니다."

**사용 원칙**:
- 1개 문제 지적 + 1개 칭찬
- 직접적 표현 피하기 ("틀렸다" X → "더 나은 방법이 있습니다" O)
- 작은 개선부터 권장

### 경험자용 (직접적으로)

**원칙**: 문제 직시 + 즉각 대안 + 높은 기준

#### 예시
- "**명사 과용.** 이 문단에서 '-의'가 12번. 절반을 동사로 전환하세요."
- "**논리 비약.** 3문단 → 4문단 연결고리 없음. 근거 2개 추가 필요."
- "**번역체 심각.** '~에 의해' 7회, '~되어지다' 5회. 전체 능동형 재작성 요망."

**사용 원칙**:
- 문제 → 구체적 수치 → 대안
- "요망", "필요", "하세요" 같은 명령형
- 칭찬은 진짜 탁월할 때만

### 전문가용 (핵심만)

**원칙**: 키워드 + 최소 설명

#### 예시
- "**Bone-2 (두괄식).** 재구조화."
- "**Flesh-11 (번역체).** 피동→능동."
- "**Soul-14 (여운).** 마지막 문장 재고."
- "**85점.** Soul-13 감정선 보완 필요. 나머지 완벽."

**사용 원칙**:
- 16가지 기준 코드 활용 (Bone-1, Flesh-6 등)
- 3~5단어로 압축
- 대안은 제시 안 함 (스스로 찾아야 함)

## 5. 금지된 피드백

### 모호한 피드백 (구체성 없음)

#### ❌ 나쁜 예시
- "좀 더 잘 써보세요."
- "이상한 것 같아요."
- "뭔가 어색해요."
- "별로네요."

#### ✅ 좋은 예시
- "3문단의 '개선의 실행'을 '개선하다'로 바꾸세요. 명사보다 동사가 강합니다."
- "논리 비약. A→Z 사이에 B, C 단계 추가 필요."
- "번역체. '~에 의해'를 능동형으로 전환하세요."

### 인격 공격 (작성자 vs 작품 혼동)

#### ❌ 금지
- "당신은 글을 못 쓰네요."
- "이런 글을 쓰다니 부끄럽지 않나요?"
- "글쓰기 재능이 없는 것 같습니다."
- "포기하는 게 나을 것 같네요."

#### ✅ 대신
- "이 글은 구조 재설계가 필요합니다."
- "현재 수준으로는 출간 불가. 수정 후 재제출하세요."
- "글쓰기 실력은 연습으로 늡니다. 이번 피드백 반영해서 다시 써보세요."

### 과도한 칭찬 (구체성 없는 찬사)

#### ❌ 금지
- "완벽합니다!" (구체적 근거 없이)
- "천재시네요!"
- "이 글 정말 최고예요!"
- "전혀 고칠 게 없습니다!"

#### ✅ 대신
- "두괄식 완벽. 첫 문장이 문단을 지배하고 있습니다."
- "이 비유 탁월. '데이터는 새로운 석유'를 '데이터는 공기'로 전복시킨 발상."
- "90점. Bone, Flesh 완벽. Soul-14 여운만 보완하면 출간 가능."

### 해결책 없는 비판

#### ❌ 금지
- "논리가 이상해요." (어디가? 어떻게 고쳐?)
- "표현이 별로네요." (뭐가? 대안은?)
- "감정이 없어요." (어떻게 넣어?)

#### ✅ 대신
- "논리 비약. 2문단→3문단 사이 근거 추가. 예: '왜냐하면 ~' 문장 1개."
- "형용사 과다. '매우 좋은' → '20% 증가한'으로 수치화."
- "감정 미흡. '완료했다' → '밤새 싸워 드디어 완료했다'로 과정+감정 추가."

### 피드백 자체의 문제

#### ❌ 금지
- 한 번에 20개 이상 문제 지적 (압도됨)
- 일관성 없는 피드백 (앞에선 형용사 쓰라더니 뒤에선 쓰지 말라고)
- 주관적 취향 강요 ("저는 이런 문체가 싫어요")

#### ✅ 대신
- 우선순위 3개만 (Bone 1개 + Flesh 1개 + Soul 1개)
- 일관된 기준 (16가지 교정 기준 준수)
- 객관적 기준 제시 ("한국어 문법상 피동형보다 능동형이 자연스럽습니다")

## 피드백 템플릿

### 기본 템플릿

```
[점수]: XX점

[강점 1개]:
- 구체적 예시 + 칭찬

[개선점 3개]:
1. [Bone 문제]: 구체적 위치 + 문제 + 대안
2. [Flesh 문제]: 구체적 위치 + 문제 + 대안
3. [Soul 문제]: 구체적 위치 + 문제 + 대안

[종합]:
- 한 줄 평가
```

### 예시

```
[점수]: 75점

[강점]:
- 두괄식 완벽. 1문단 첫 문장 "AI는 창작을 돕는다"가 전체를 지배합니다.

[개선점]:
1. Bone-3 (팩트): 2문단 "대부분 작가들이" → "2024년 설문조사에서 67% 작가가"
2. Flesh-6 (형용사): 3문단 "매우 놀라운 결과" → "3배 증가한 결과"
3. Soul-14 (여운): 마지막 "이상입니다" → 독자에게 질문 던지기

[종합]:
- 구조 탄탄, 표현 보완 필요. 위 3개만 수정하면 출간 가능.
```

## 사용 가이드

### 피드백 순서
1. **전체 점수 먼저** (70점, 85점 등)
2. **강점 1개** (구체적 예시)
3. **개선점 3개** (Bone → Flesh → Soul 순)
4. **종합 한 줄**

### 강도 선택 기준
