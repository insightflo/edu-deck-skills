## 표지 직접 설계 계약

표지(01)는 [authoring.md](authoring.md) 3절 4방식 중 내용에 맞는 방식으로 만든다. 카탈로그 16종은 그대로·변형·조합의 재료다 — 실패 폴백 전용이 아니다. 새로 설계하든 카탈로그를 고치든 표지가 지켜야 할 계약:

- 형태: `<section class="slide cx" data-archetype="cover" data-variant="custom" id="cover">`. `custom` 은 "카탈로그 id 가 아닌 직접 설계"를 뜻하고, `custom-<짧은이름>` 도 허용한다.
- 제목은 `.cx-title` 안에 둔다(모션 엔진이 제목 맞춤·장 전환 공유 제목으로 쓴다). 교육 이름·상단 소개글은 `.cx-eyebrow` 에 둔다.
- 색은 `var(--…)` 토큰만 쓴다(테마 호환). 하드코딩된 `#…` 색은 검사가 WARN을 낸다.
- `<script>`·외부 자원(이미지·글꼴·스크립트 로딩) 금지 — 기존 슬라이드와 같은 검사다.
- 장식 요소(그림·띠·배경 패널)에는 `aria-hidden="true"` 를 단다. 장식만 슬라이드 밖 넘침 검사를 면제받고, 글자를 담은 요소는 일반 장과 같은 기준으로 잰다.
- 글자 18px 이상(권장 20px). 슬라이드 밖 넘침·상자 밖 글·대비·겹침도 일반 장 기준과 같다.
- 단계 없음(`data-step` 없음). 발표자 노트는 `<aside class="notes">` 로 둔다.
- 카탈로그 변형을 그대로 쓸 때는 그 조각의 형태(`data-variant="<id>"`)를 유지하며, 그 사실은 최종 보고에 `표지: 카탈로그 <id>` 한 줄로 남긴다. `.cover-art` 자리표시 그림은 주제 그림으로 다시 그린다(아래 절).

## 표지 그림 자리(cover-art)

카탈로그 표지의 주제 비특정 장식·일러스트 자리는 `class="cover-art"` 로 표시된 **자리표시 그림**이다 — 파선 틀 + `«그림: …»` 안내. 저작자는 안내를 지우고 주제에 맞게 다시 그린다:

- 자리(위치·면적)는 변형이 유지한다. 안에는 `k-*`/`t-*` 도식 문법(diagrams.md) 또는 표지용 기하(도형·아이콘 조합)로 주제 일러스트를 그린다. `aria-hidden` 유지, 색은 `var(--…)` 토큰만.
- 자리표시 그림(`«…»`)이 그대로 남으면 «…» 텍스트 자리와 같은 검사 ERROR(`--allow-placeholders` 에서만 묵음).
- 뼈대가 곧 변형 정체성인 구성(블루프린트 격자·바우하스 기하·학습 경로·노트 판형·포털·카드 스택·bigstat/stripes 타이포 장식)은 자리가 아니다 — 그대로 쓰고 글자 자리표시만 채운다.

## 그림 자리(fig-slot)와 텍스트 나열

모든 계열이 쓸 수 있는 공용 그림 자리: `<figure class="fig-slot">` — 자리·비율·정렬은 배치(계열 변형)가 지정하고, 내용은 저작 에이전트가 `diagrams.md` 문법의 `svg.dg`로 그린다(도형 `k-*`·글자 `t-*`·화살표·`data-step` 계약 동일). 빈 슬롯·`«…»` 자리표시 잔류·`role="img"`+`aria-label` 누락은 검사 ERROR. 현재 fig 변형을 싣는 계열: **02 agenda · 06 traits-grid · 11 levels · 17 statement · 26 rules-dark**(`data-variant="fig"`). 팩 덱에서도 그대로 쓴다(resource-packs.md).

`check_deck.py`는 본문 장의 계열을 아래 셋으로 나눠 **텍스트 나열**을 경고한다 — 고정 형식 장을 뺀 연속열에서 텍스트 계열만 **5장 이상** 이어지면 WARN(“시각 계열을 섞으세요”).

- **시각으로 센다**: 도식·차트 계열(timeline·map·mechanism·traits-grid·meter·compare-2·compare-table·hub·levels·tile-grid·sequence·mapping·build-up·stat-strip·chart-bar·chart-line) + 모형(mock-legend·mock-options) + 채팅(worked-example) + 구성도(arch-flow) + 사분면(quadrant) + 플래시카드(flashcards) + **`data-variant="fig"` 또는 `.fig-slot` 보유 장** + **미니 흐름(`.vflow`·`.vpills`) 보유 장**. 연속열을 끊는다.
- **고정 형식(연속열에서 제외 — 세지도 끊지도 않는다)**: cover·quiz-ab·quiz-sort·quiz-ox·check·sources·closing·explore·detail-sheet·**part-divider**(+screen-cite 조각 — 아키타입 mapping 이라 시각으로 센다). 고정 형식은 아키타입으로 확정 — 안에 미니 흐름이 있어도 제외다.
- **텍스트로 센다**: agenda·statement·frame-form·before-after·rules-dark·checklist (아키타입 없는 팩 장도 텍스트 — `.fig-slot` 을 얹으면 시각이 된다).

그림 자리는 도식 자리다 — 원본자료의 주요 이미지(실물 사진·원본 도면·표)는 슬롯이 아니라 화면 인용(screen-cite, 32) 계약으로 싣는다(composition.md '사진 습관 → 시각 체험').

## 자주 하는 조정

- **카드·칸 개수 줄이기**: 해당 요소를 지우고 남은 `data-step` 번호를 1부터 다시 매긴다.
- **모형 창이 넘칠 때**: 말풍선·행 수를 줄인다. 글자 크기를 20px 아래로 줄이지 않는다.
- **모형 내용이 짧아 창 아래가 비어 보일 때**: 창에 `style="align-self:flex-start"` 를 준다(22번 조각의 문서·표·양식·메일 창은 이미 이렇게 되어 있다). 채팅·단체방 창은 앱처럼 세로를 채워 두어도 된다.
- **채팅이 아닌 주제의 모형 창**: 14·15·16·18·19·20번 조각의 모형 창은 채팅 화면(`.main`·`.msgs`·`.u`·`.a`·`.av`·`.input`)이다. 대화형 도구가 아닌 주제면 `win-body` 안을 문서·표·양식·메일·단체방 마크업(`references/classes.md` 모형 창 표)으로 바꾼다. `data-step`·`data-add`·`data-only` 같은 단계 속성은 바꾼 요소로 옮기고, `.av`(말하는 쪽 표시)·`.model`·`.input` 은 지운다. 바꾼 뒤 `check_deck.py` 로 잘림을 확인한다.
- **도식 글(SVG text)**: 줄바꿈이 안 된다. 한도를 넘기면 낱말을 줄이거나 `<tspan x="…" dy="30">` 으로 두 줄을 만든다.
- **색 바꾸기**: 조각의 `#2F6FB0`(파랑)·`#E8772E`(주황)는 의미 색이다. 의미가 반대면 서로 바꾼다.
- **조각에 없는 배치가 필요할 때**: 새로 설계해도 된다(authoring.md 2·3절) — 작업 폴더 `src/` 안에서 기존 셸 클래스(card, row, col, win …)와 덱 전용 클래스로 만든다. `data-archetype`은 검사기가 아는 계열 이름만 쓰거나 아예 생략한다(없으면 엔진이 자동 배정한다. 모르는 이름은 검사 ERROR다).
