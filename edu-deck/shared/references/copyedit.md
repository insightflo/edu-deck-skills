> **로드 시점**: 4단계 조각 작성을 마치고 첫 조립이 깨끗이 끝난 직후 — 6단계 최종 검사 전에 반드시 거친다. 이후 화면 글·노트를 크게 고쳤을 때도 다시 거친다.

# 말투 교정(필수)

슬라이드 초안의 한국어는 AI 티(번역투·빈 문장·기계적 병렬)가 남기 쉽다. 이 절차는 화면 글과 발표자 노트를 덱 밖으로 뽑아 세 스킬로 순서대로 고치고, 안전하게 되돌린다. **교정 없이는 완료 보고를 하지 않는다.**

## 1. 도구와 파일

- `scripts/extract_copy.py <덱 폴더>` — src 조각의 화면 글·노트를 `qa/copy/copy.md` 로 뽑는다. 각 줄에 `[파일:번호|힌트]` 위치 태그와 파일별 sha256 이 붙는다.
- `scripts/extract_copy.py <덱 폴더> --apply qa/copy/copy.edited.md` — 고친 줄만 src 에 되돌린다. 태그·속성·구조는 건드리지 않고, 숫자·고유명사(라틴 단어)·「」제목이 원문과 다른 화면 줄과, 사실 칩·출처 줄·태그가 섞인 줄은 `보류` 로 돌린다. 결과는 `qa/copy/apply-report.md` 에 남는다.
- 교정본을 만들 때는 `copy.md` 를 `copy.edited.md` 로 복사해 `내용` 부분만 고친다. 위치 태그·`#` 머리줄·`##` 장 제목은 바꾸지 않는다(어기면 그 줄은 보류된다).

## 2. 순서

1. **추출** — `extract_copy.py` 로 `qa/copy/copy.md` 생성.
2. **진단 — red-pen 스킬** — copy.md 를 넣고 구조·표현·군더더기 중심으로 진단 → `qa/copy/feedback.md` 저장. '감정·여운' 같은 산문 기준은 슬라이드 글에 맞지 않으므로 화면에는 적용하지 않고 노트에만 가볍게 참고한다.
3. **윤문 — humanize-korean 스킬** — 진단을 반영해 화면 글과 노트를 모두 고쳐 `qa/copy/copy.edited.md` 생성. 숫자·이름·인용·사실 칩·코드·메뉴명(의미 앵커)은 그대로 둔다.
4. **마무리 점검 — im-human 스킬** — 쉬운 존댓말인지, 전문 용어가 노트에서 처음 나올 때 한 줄 풀이가 있는지, 없는 사실을 넣지 않았는지 확인한다. 화면 글 길이 한도(`expression.md` 2절)는 유지한다.
5. **되돌리기·재검사** — `extract_copy.py --apply qa/copy/copy.edited.md` → `build_deck.py` 재조립 → `check_deck.py` + `verify_sources.py` 다시 통과 → `apply-report.md` 를 qa 폴더에 보존한다.
6. **보고** — 완료 보고에 교정 결과를 적는다: 바뀐 줄 수, 보류 줄(위치·이유), 실행 못 한 스킬.

## 3. 바꿔도 되는 것과 안 되는 것

- **된다**: 어미·문장 순서·쉬운 말로 바꾸기·군더더기 삭제. 제목은 계속 `expression.md` 제목 규칙을 따른다.
- **안 된다**: 사실·수치·이름·인용문·단계 순서·확인 문제 정답·장 수·슬라이드 구조(태그·속성·클래스). 사실 칩(`.fact`)·출처 목록(`.src-list`)·증거 지표(`.stat`)는 도구가 강제로 보류한다 — 고치려면 src 를 직접 편집하고 `verify_sources` 를 다시 돌린다.
- 화면 글에서 숫자·라틴 단어·「」제목이 원문과 다르면 되돌리기가 보류로 돌린다 — 실수로 수치를 갈아 엎는 사고를 막는 안전장치다. 노트 줄은 이 검사를 하지 않으니, 노트의 수치·이름은 사람이 한 번 더 눈으로 확인한다.

## 4. 스킬이 없을 때 — 내장 체크리스트

해당 스킬을 불러오지 못하면 `<스킬> 실행 못 함(미설치)` 이라고 보고에 적고, 그 단계는 아래 목록으로 대체한다. **실행하지 않은 스킬을 실행한 것처럼 적지 않는다.**

- [ ] 번역투 피동 `~되어지다`, `~에 의해` → 능동으로
- [ ] `~를 통해` 남발 → `~로`·생략
- [ ] 명사 사슬 `~의 ~의 ~` → 풀어쓰기
- [ ] 과한 수식 `매우·정말·다양한·효과적인` → 삭제
- [ ] 기계적 3항 병렬(모든 문장이 셋셋 나열) → 리듬 깨기
- [ ] 어미 `~라고 할 수 있습니다`, `~것입니다` → 단정하게
- [ ] 접속사 남발 `그리고·또한·따라서` → 필요한 것만
- [ ] 영어 직역 `~하는 것이 중요합니다` → `~하세요` 처럼 직접
- [ ] 같은 어미·길이 반복 리듬 → 길이 섞기
- [ ] 과장 `혁신적·획기적·강력한` → 구체 사실로
- [ ] 뜻 없는 마무리 `이제 ~해 보세요!` → 다음 장 안내 또는 삭제
- [ ] 이모지·느낌표 연발 → 없애기(덱 규칙상 사용 안 함)
