# 구성도·업무 흐름 부품 (`data-c="stack"`)

시스템 구성·제품 층·처리 단계·상태 전이·분기·연동 그림을 **좌표 없이** 그린다. 작성자는 노드의 행·열 칸과 연결 관계만 `data-d` 에 쓰고, 상자 위치·그룹 띠·화살표 경로는 `assets/kit/stack.js` 가 규칙으로 계산해 SVG 를 만든다.

포팅 원천은 `caru-ini/stack-diagram`(MIT)의 기하·경로 규칙이다. 뷰어·로고 내려받기·갤러리 기능은 옮기지 않았다.

## 마크업

```html
<figure class="viz-fig">
  <div class="stack-fig" data-c="stack" role="img" aria-label="도식 요지 한 문장"
       data-d='{"nodes":[…],"edges":[…],"groups":[…]}'></div>
  <figcaption>그림 설명</figcaption>
</figure>
```

- `role="img"` + `aria-label` 은 읽기 계약 — 누락은 check_deck ERROR.
- `data-d` 는 **작은따옴표 JSON**: 속성은 `'…'`로 감싸고 내부는 큰따옴표만. JSON 안에 `'`(어포스트로피)가 있으면 빌드 실패다.
- 같은 figure 안에 `k-*`·`.tile`·`.ed-diagram` 같은 레거시 도식 클래스를 **섞지 않는다**(부품이 도식 전체를 소유). 다른 장·다른 figure 에서의 공존은 자유.

## data-d 형식

| 키 | 형태 | 규칙 |
|---|---|---|
| `nodes` | 배열, 2~14개 | `{id, name, icon?, row, col, role?, badge?, tone?}` |
| `edges` | 배열, ≤20개 | `{from, to, label?, kind?}` — from·to 는 노드 id |
| `groups` | 배열, ≤5개 | `{id, label, icon?, nodes, cols?, tone?, parent?}` |

### 노드

| 키 | 규칙 |
|---|---|
| `id` | 노드·간선·그룹이 참조하는 고유 문자열 |
| `name` | 타일 아래 굵은 글자. `«항목 ≤8자»` 예산 |
| `row` | 0~2 (위에서 아래로) |
| `col` | 0~5 (왼쪽에서 오른쪽으로) |
| `icon` | `assets/kit/vendor/lucide-subset.json` 의 101개 Lucide 이름만. 로고·브랜드 마크 금지 |
| `role` | 이름 아래 작은 글자. `«역할 ≤11자»` 예산 |
| `badge` | 타일 왼쪽 위 원형 번호(숫자·문자) |
| `tone` | `plain`(기본)·`brand`(강조 테두리·틴트)·`dark`(잉크 칠) |

같은 `(row, col)` 칸에 두 노드는 금지(빌드 실패). 격자 범위를 벗어나는 row·col 도 오류다.

### 간선

| 키 | 규칙 |
|---|---|
| `from`·`to` | 노드 id. 양방향 쌍이면 ±9px 로 나란히 벌려 그린다 |
| `label` | 선 위 설명. `«관계 ≤7자»` 예산 |
| `kind` | `main`(굵은 강조 실선)·`sub`(가는 보조 실선)·`dash`(점선 — 예외·비동기·롤백) |

경로 규칙: 세로 간선은 위 노드 **글자 아래**에서 아래 노드 타일 위로 내려가 글자를 가로지르지 않는다. 같은 줄 먼 노드는 위쪽 통로로, 행·열이 모두 다르면 열 사이 틈과 행 사이 띠로만 꺾는다 — 어떤 경로도 끝점이 아닌 노드 상자를 지나지 않는다(테스트가 300개 무작위 격자로 검증한다).

### 그룹

| 키 | 규칙 |
|---|---|
| `id`·`label` | 묶음 이름. `«주체 ≤6자»` 예산 |
| `nodes` | 이 묶음에 속한 노드 id 배열(직사각 형태여야 함) |
| `cols` | `[c0,c1]` — 노드 나열 대신 열 범위로 묶을 때 |
| `parent` | 다른 그룹 id — **한 단 중첩까지만** |
| `tone`·`icon` | 노드와 같은 어휘 |

그룹 상자가 멤버가 아닌 노드를 덮으면 ERROR. 그룹의 노드 나열이 직사각(연속 행·열)이 아니면 ERROR. 그룹은 노드·화살표보다 먼저 그린다(등장도 그룹→노드→화살표 순).

## 크기·높이

도식은 가로 100%로 그리고 **최대 높이 600px** 를 넘지 않는다. 자연 높이가 넘으면 비율을 유지한 채 줄어든다 — check_deck 이 "줄여 그립니다" WARN 을 낸다. 3행×3그룹처럼 큰 그림은 줄어 보일 수 있으니 노드 수를 나누거나 col 을 줄인다.

## 색·어두운 장

색은 슬라이드 토큰만 쓴다: `--ink`(글자·테두리), `--paper`(타일 바탕), `--line`(보조 테두리), `--soft`(역할·라벨), `--accent`(주요 화살표·강조 노드). `.slide.dark` 장에서는 부품 전용 변수(`--sf-*`)가 어두운 매핑으로 자동 전환된다 — 작성자가 따로 할 일은 없다. 팩 덱의 글꼴은 `--pack-sans` 를 따라간다.

## 등장·정적 모드

- 장에 들어오면 그룹→노드→화살표·라벨 순으로 등장(실행 이름 `stack-reveal`, `eduMotion.sigLog` 기록).
- `data-step` 을 도식 내부에 쓰지 않는다 — 순서는 부품 소유. 캡션·요약 글자에는 줄 수 있다.
- 인쇄·PDF·자습·동작 줄이기·발표자 모드·캡처에서는 **완성 그림**이 그대로다.
- 한 번 본 장에 다시 와도 재생하지 않는다. 창 크기가 바뀌면 다시 계산해 그린다(재생은 없음).

## 아이콘·라이선스

아이콘은 `assets/kit/vendor/lucide-subset.json` 에 고정 복사된 101개 Lucide(lucide-static **1.69.0**, ISC, `LICENSE-lucide.txt`·lucide.dev 출처). 이름이 목록에 없으면 빌드가 거절한다. 새로고침이 필요하면 `scripts/fetch_lucide.py` 가 네트워크에서 고정 목록을 다시 쓴다 — 기본은 오프라인 사본 그대로다.

## 검사

- 빌드(`build_deck.py`): data-d 스키마 오류 → 빌드 실패. 규칙의 주인은 `scripts/stack_schema.py`.
- `check_deck.py`: role/aria-label·스키마 형태(ERROR)·격자 넘침·그룹 덮음(ERROR)·도식 600px 축소(WARN)·시그니처 발화 감사.
