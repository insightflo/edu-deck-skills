# edu-deck — Portable education deck skills

교육용 HTML 덱과 여러 편을 묶은 학습 포털을 만드는 스킬 묶음입니다. Pi 설치는 필요하지 않습니다. Claude·ChatGPT를 포함해 파일과 Python 실행 도구를 가진 에이전트에서 사용할 수 있도록 구성했습니다. **제품별 업로드·자동 등록 성공은 검증하지 않았습니다.**

## 어떤 ZIP을 쓰나요?

- **`edu-deck-portable-family.zip`**: 로컬 에이전트용. `edu-deck/`, `edu-deck-solo/`, `edu-deck-series/`가 이웃 폴더입니다. `edu-deck/SKILL.md`부터 읽습니다.
- **`edu-deck-portable-single-root.zip`**: 한 폴더로 전달할 때 사용합니다. 최상위 `edu-deck/SKILL.md`가 안내문이며 원본 세 스킬은 `edu-deck/bundle/` 안에 있습니다. 사용자 스킬 ZIP을 받는 Claude 환경에서는 등록 후보로, ChatGPT에서는 실행 능력이 있을 때 작업 자료로 사용할 수 있습니다. 업로드가 설치를 뜻하지는 않습니다.

두 ZIP의 원본 기능과 자산은 같습니다. 둘을 동시에 설치할 필요는 없습니다. 기존 설치를 덮어쓰지 말고 새 폴더에서 확인하세요. 형제 폴더 관계를 유지해야 공통 자산과 시리즈 조립기가 연결됩니다.

## 시작 요청 예시

ZIP을 풀 수 있는 환경에서 다음 요청과 주제·청중·교육 시간을 함께 전달하세요.

> 첨부한 edu-deck 묶음을 풀고 최상위 edu-deck/SKILL.md를 읽어 주세요. 연결된 원본 스킬도 읽고 그 절차를 따르세요. 먼저 파일 접근, Python, 검사 모듈, 브라우저, 웹 조사 가능 여부를 확인하세요. 없는 기능은 알리고 검사 기준을 낮추지 마세요. 주제는 [주제], 청중은 [대상], 시간은 [분]입니다. 구성안을 먼저 보여 주세요. 설치·외부 업로드는 별도 승인 없이 하지 마세요.

자세한 실행 조건은 `USAGE.md`, 권리 안내는 `NOTICES.md`를 읽습니다. 플랫폼별 설명의 기준 문서는 원본 `edu-deck/shared/references/runtimes.md`입니다(단일 루트에서는 `bundle/` 아래).

## 포함 / 제외

포함: 세 스킬 전문, 디자인 8종·학습 흐름 8종, 조각·아이콘·폰트, 모션·반응형 런타임, 조립·검사 도구, 시리즈 포털 템플릿, 파일별 SHA256 목록(`release-manifest.json`).

제외: 개발용 재생성 도구, 개인 교육 사례·다운로드 원본, 작업 로그, 캐시, 백업, 이전 ZIP. 개발 문서가 언급하는 `shared/dev/port.py`는 배포본에 없습니다. 참조 문서의 `shared/dev/` 링크와 개발 회귀 검사 명령은 원본 개발 환경용이며 배포본에서 실행하지 않습니다. 일반 덱 작성은 포함된 팩과 조립기를 사용하며 셸 자체를 재생성하지 않습니다.

결과물은 외부 자산 요청 없이 열리는 HTML입니다. 다만 교육 내용 조사와 출처 확인에는 별도 자료·네트워크가 필요할 수 있습니다. 생성기는 완성된 교육 내용을 대신하지 않습니다.

## 검증 범위

배포 검증은 ZIP을 별도 폴더에 풀고 원본 소스 경로 없이 단일 덱과 시리즈를 생성·검사하는 방식입니다. 실제 Claude/ChatGPT 계정에 업로드·등록하거나 모든 플랫폼을 시험했다는 뜻은 아닙니다. Python 3.11 환경을 기준으로 검증하며 다른 버전·운영체제의 동작은 현지에서 확인하세요.
