# 자료를 책 쪽으로 나누는 법

## 1. 먼저 뽑을 것
읽는 사람, 바꾸면 안 되는 사실(숫자·날짜·고유명), 장 구성, 사례 쌍(이야기+근거), 출처 있는 그림, 마무리에 남길 한 문장.

자료에 없는 숫자는 만들지 않는다. 없으면 `○○` 로 두고 알린다.

## 2. 기본 순서
표지(cover) → 목차(toc) → 개념·요약 본문(article, 필요하면 `t-tint` / `t-dark`) → 부 시작(divider) → 사례는 **이야기(story) + 근거(evidence) 한 쌍** → 정리·체크리스트(article) → 뒤표지(back).

사례가 많으면 divider 로 부를 나누고, 같은 유형의 본문만 세 쪽 넘게 잇지 않는다. 빈 쪽(`blank`)은 인쇄 면맞춤이 필요할 때만 쓴다.

## 3. 한 쪽에 담을 양
판면은 600×820, 본문 여백은 대략 42~44px. 글은 15px 전후. 한 쪽은 제목 하나와 블록 두세 개가 알맞다. 바닥글·포인트 바·링크 바(`data-dock`)와 본문이 겹치면 안 된다. 빌드 후 반드시 `preview.py check` 로 넘침을 본다.

## 4. 제목
표지 제목은 짧고 줄바꿈을 직접 넣는다. 강조할 낱말만 `<em>` 으로 감싼다. 본문 `.h1` 은 한두 줄, 사례 `h2` 는 결과나 변화가 보이게.

## 5. 그림
원문 사진·도식만 쓴다. `img/` 에 두고 상대 경로로 넣으면 빌드가 data URI 로 묶는다. 사진 칸(`.photo`, `.b-figure`)에는 `figcaption` 에 출처를 쓴다. 그림이 없으면 `.nophoto` 를 남기지 말고 개념도(SVG)로 채운다. 없는 현장을 사진처럼 지어내지 않는다.

## 6. 사실
통계, 기관명, 인용, URL 은 원문 그대로. 샘플 템플릿의 숫자(18→3분 등)는 구성 예시이므로 실제 책에 복사하지 않는다.
