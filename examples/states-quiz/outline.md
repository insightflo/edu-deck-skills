# 구성안: 물질의 상태 변화 단원 평가 퀴즈
- 청중: 중학교 1학년 학생 (단원 평가를 앞두고 스스로 점검)
- 시간: 15분 · 장 수: 15장 · 주제 유형: (d) 개념·리터러시를 확인 문제 평가형으로 재배치 · 기준일: 2026-11-05
- 교육 뒤 청중이 할 수 있는 것: ① 상태 변화 6종의 이름과 방향을 말한다 ② 1기압에서 물의 어는점(녹는점) 0℃·끓는점 100℃를 안다 ③ 입자 배열·간격·운동으로 세 상태를 구분한다
- 가정: 특정 교과서·학교 정보 없음 → 일반 중1 과학 범위 표현. 최종 보고 "확인 필요"에 남김
- 경로: legacy 아키타입(리소스팩 미사용, 3.5단계 생략). 확인 문제 7장 중심, 개념 정리 3장 최소 구성
- theme/arc: `ocean` · `warmup` — tone_router 후보(theme: ocean/solar/cobalt, arc: follow/warmup/hook)에서 선택. arc 는 라우터 1순위 follow(따라하기형) 대신 2순위 warmup 을 택했다 — 퀴즈 평가 덱은 선지식을 깨우는 문항으로 여는 것이 절차 지도보다 장르에 맞다(warmup 은 퀴즈형 전용 arc). 첫 장은 quiz-ox, 14→15장으로 1장 추가.
- 반복 틀: "이름·방향" · "0℃·100℃" · "입자 모형" (closing 알약·summary에 재등장)

- 리듬 분포: 앵커 4 · 밀집 10 · 숨고르기 1. 밀집 10장 연속(04~13)은 평가 덱의 의도된 구성이다 — 문항 장이 check 확장·기본·quiz-ab·quiz-sort·quiz-ox 네 유형으로 섞여(07~13) 같은 리듬이 반복되지 않고, 문항 유형 묶음(용어3·온도2·입자2)과 다시 보기 복귀로 연속 밀집의 단조를 나눈다(design.md 4절: 의도된 연속은 단조가 아니다). 숨고르기는 도입 워밍업 1장 + 앵커 장들이 모드 전환을 담당.
- 확인 문제 배치: 용어 3(07~09) · 온도 2(10~11) · 입자 2(12~13). 7문제 모두 `.chk` 계약(눌러 답하기·해설·다시 풀기·다시 보기).
- 아키타입 연속: map 3장(04~06)은 한도(3장) 안이고 구성이 셋 다 다르다(방향 보드·온도 사다리·매트릭스 표). 07~13 문항 장은 check 확장·기본(07·10·13)과 quiz-ab(08·11)·quiz-sort(09)·quiz-ox(12)로 4유형 혼합 — 같은 유형 연속 없음.
- 파트를 여는 statement·rules-dark·checklist는 15장 분량과 "확인 문제 비중 최대" 지시에 따라 생략: statement 역할은 agenda 정리 문장이, rules-dark 역할은 closing 알약 3개가 대신한다. warmup 의 선지식 깨우기 역할은 02 quiz-ox 가 맡는다.
- 숫자(100℃·0℃)가 나오는 장(05·10·11)과 드라이아이스 사실(08)에만 칩. 6종 이름·입자 모형은 일반 개념 설명으로 칩 없이 쓴다(research.md F05~F07 참고).
