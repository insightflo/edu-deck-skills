# brief: 중1 과학 물질의 상태 변화 — 단원 평가 퀴즈 덱

- 주제: 중학교 1학년 과학 '물질의 상태 변화' 단원 평가 퀴즈 덱 (공개 저장소 예시용)
- 청중: 중학교 1학년 학생 (학습 범위: 상태 변화 6종, 어는점·녹는점·끓는점, 입자 모형 관점)
- 시간: 15분 · 장 수: 15장 (warmup arc 도입으로 도입 퀴즈 1장 추가)
- 교육 뒤 청중이 할 수 있는 것:
  1. 상태 변화 6종(융해·응고·기화·액화·승화)의 이름과 방향을 말한다
  2. 1기압에서 물의 어는점(녹는점) 0℃, 끓는점 100℃를 안다
  3. 고체·액체·기체의 입자 배열·간격·운동 차이로 상태 변화를 설명한다
- 덱 형태: 확인 문제(check, `.chk` 계약) 중심의 단원 평가. 보기를 눌러 답하고, 틀리면 해설과
  "다시 보기"(개념 장 복습)·"다시 풀기"가 나온다. 핵심 개념 정리는 퀴즈 풀이에 필요한 최소 3장.
- 경로: legacy 아키타입(리소스팩 사용 안 함 — 사용자가 선택하지 않았다). 3.5단계 생략.
- theme/arc: `ocean` · `warmup` (tone_router 추천 후보에서 선택 — arc 는 1순위 follow 대신 퀴즈형 전용 warmup).

## 표지 방향 3안 (비교 후 채택)

| 안 | 변형 | 구성·기조 |
|---|---|---|
| 1 | bigstat | 오른쪽 절반이 큰 글자 "6갈래" — 숫자 하나로 단원을 압축하는 강조형. 굵고 선언적 |
| 2 | diagram | 오른쪽에 물질(입자) 중심 + 고체·기체·액체가 이어진 삼각 도식 — 개념 관계를 보여 주는 구조형 |
| 3 | orbit | 오른쪽에 궤도 도는 상태 아이콘(큐브·물방울·구름) — 세 상태가 돌아가는 움직임형 |

- 채택: **1안 bigstat** (비교 캡처: `qa/cover-compare/1-bigstat.png`·`2-diagram.png`·`3-orbit.png`)
- 근거: 덱의 반복 틀 "여섯 갈래"와 첫인상이 정확히 일치 — 거대 활자 "6갈래"가 단원의 핵심 수를 2초 안에 전달한다(2초 테스트 최강). diagram은 개념 지도를 미리 보여 주나 액체 점선 원이 미완성으로 읽히고, orbit은 장식적이나 정보 부하가 낮다. tone_router 추천(bigstat)과 육안 판단이 일치.
- 공개 예시 제약: 교과서·타인 문장·외부 CSS/SVG/이미지 복사 금지. 글은 직접 쓰고
  수치(0℃, 100℃ 등)는 공개 출처에서 확인해 data-src 칩으로 표기. 실제 개인정보·라스터 금지.

## 청중 → 수행 행동 → 완료 증거 → 흐름 → 선택 이유 (구성 근거)

- 청중: 중1 학생. 단원을 한 번 배웠고 평가로 점검하는 단계. 혼자서도 풀 수 있어야 한다.
- 수행 행동: 확인 문제 7문제를 보기를 눌러 스스로 푼다 → 틀리면 해설을 읽고 개념 장으로 돌아가 다시 본다.
- 완료 증거: 확인 문제 정답률 + 틀린 문제의 "다시 보기" 이동. 문제는 단원 평가 기출 유형
  (용어·방향, 온도 수치, 입자 모형)을 두루 겨냥한다.
- 흐름: 개념 되짚기 3장(6종 지도 → 온도 → 입자 모형) → 확인 문제 3묶음 7문제(용어 3 · 온도 2 · 입자 2)
  → 참고 자료 → 마무리. 유형은 composition.md 2절 (d) 개념·리터러시 계열을 퀴즈 평가형으로 재배치.
- 디자인: legacy 경로(공용 아이콘·개념 SVG 도식). 이유: 공개 예시로 공용 자산만 쓰는 것이
  라이선스·재현성에서 가장 안전하고, 사용자가 리소스팩을 요청·선택하지 않았다.
