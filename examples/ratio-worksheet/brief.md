# brief: 초등 6학년 수학 「비와 비율」 학습지 덱

- 주제: 초등학교 6학년 수학 「비와 비율」 단원 학습지 (인쇄 중심)
- 청중: 초등학교 6학년 학생 — 교사 없이 스스로 20분 동안 공부하는 분량
- 시간: 20분 · 장 수: 10장 (팩 경로 재구성)
- 용도: 공개 저장소(edu-deck-skills) 예시 덱. 인쇄(P 브라우저 인쇄, 한 쪽에 한 장)해서 그대로 나눠 주는 학습지.
- 교육 뒤 청중이 할 수 있는 것:
  1. 두 수를 비로 나타내고 앞항·뒷항을 말할 수 있다 (예: 6:3)
  2. 문제에서 기준량과 비교하는 양을 찾아 비율을 분수·소수로 구한다
  3. 비율을 백분율로 바꿔 인원이 다른 두 집단을 비교한다

## 경로·구성 선택

- 경로: **리소스팩 workbook · 흐름 compare** (팩 경로 재생성 · 자유 모드).
- 주제 유형: (d) 개념·리터러시 + (c) 스킬 연습 혼합. 학습지이므로 개념 → 예제 → 연습 → 정답 순서를 compare 흐름에 실었다.
- 청중 → 수행 행동 → 완료 증거 → 흐름:
  - 초6 학생(분수·소수 연산 가능) →
  - 수행 행동: 혼자 학습지를 풀고 정답면으로 채점 →
  - 완료 증거: 해보기 문항 + 확인 .chk 2문항을 스스로 맞힘 →
  - 흐름: 기준 정하기(02~03) → 나누기(04~05) → 판단(06) → 조건 변경·적용(07) → 확인(08) → 정답·정리(09~10).
- 반복 틀: "기준량 → 비교하는 양 → 나누기" (compare 4단계 자체가 이 틀의 확장)

## 팩 디자인 선택 (3안 비교 — 표지 3안 절차와 동일 역할)

preview_pack으로 실제 팩 시안 3종을 생성·캡처해 비교하고 1안을 채택했다 (pack 경로는 프리뷰 비교가 표지 3안 비교를 대신한다).

| 안 | 디자인 | 판정 |
|---|---|---|
| 1안 | **workbook** | ✅ 채택 — 읽는 면+해보는 면 마주본 페이지가 '교사 없는 자습 학습지'와 정확히 대응. 해보는 면의 빈줄·pencil 장식이 인쇄 학습지 문법 그대로 |
| 2안 | atlas | 폐기 — 관계 지도 탐색용. 이 덱의 핵심 행동은 '관계 탐색'이 아니라 '직접 계산·기록'이라 읽기만 되는 판면으로는 해보기 면을 못 담음 |
| 3안 | editorial | 폐기 — 큰 질문+본문 열의 읽기 중심 구성. 연습 문항·빈칸 활동이 주인 학습지에는 기록 면이 없어 약함 |

- 라우터 추천 workbook(4.689)과 동일 — `preview_pack.py record`(by=default)로 deck.json에 기록됨.
- 프리뷰 경량 검사: `RESULT: PASS errors=0 warnings=0 info=2 render=RUN slides=8`
- 비교 증거: `qa/preview-workbook.png · qa/preview-atlas.png · qa/preview-editorial.png` (또는 preview 축소판)

## 인쇄(P) 설계 결정

- 인쇄 요구가 핵심: 문제 면에는 정답을 두지 않는다(workbook-answer의 빈줄은 입력 칸이 아니라 종이에 쓰는 안내).
  정답은 09장 「정답으로 채점하고 정리합니다」 한 면에 모은다 — 종이 학습지의 뒷면 정답면 관례.
- 확인 문제는 `.chk` 2문항(08장): 인쇄 시 보기만 찍히고 정답·해설은 숨겨진다(셸 동작 확인 완료).
- **quiz-ab·quiz-ox 미사용(구성 안내와의 차이)**: 이 퀴즈들은 인쇄 시 모든 단계가 펼쳐져
  정답이 그대로 찍혀 인쇄 학습지 요구와 충돌한다 — `.chk` 확인 문제 2문항으로 대체한다.
- deck.json `summary`는 인쇄(P) 한 장 요약이 학습지 핵심 정리로 쓰이도록 충실히 작성.
- 노트(발표 대본)는 선생님·보호자 지도용 안내로 작성(정답은 노트가 아니라 정답장에).
