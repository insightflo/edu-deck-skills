# Brief: 개인정보 보호 기본 (직장인 20분)

- 주제: 직장인 대상 개인정보 보호 기본 교육
- 청중: 비전공 일반 직원 (사무직, 법률 지식 없음)
- 형식: talk 덱 — 발표자가 넘기며 진행하는 강의. 발표자 노트(대본) 충실.
- 시간: 20분 · 장 수: 14~18장 (목표 16~17장) · 기준일: 2026-11-05
- 공개 예시 덱: 특정 회사 언급 금지, 일반 직장 상황 + 가명 예시. GitHub 공개 저장소 예시로 배포.

## 교육 뒤 청중이 할 수 있는 것
1. 개인정보(법적 정의 기준)를 알아보고 고유식별정보를 구분한다
2. 모을 때·쓸 때·버릴 때의 기본 행동(최소 수집, 마스킹·잠금, 파기)을 말한다
3. 개인정보가 새어 나갔을 때 즉시 해야 할 일(전파 중지·보고)을 안다

## 선택 이유 (청중 → 수행 행동 → 완료 증거 → 흐름 → 디자인)
- legacy 아키타입 경로 · **자유 모드** 재생성
- 주제 유형: (b) 법규·안전·컴플라이언스
- 수행 행동은 '판단 → 습관 → 사고 대응'의 3단 확인 구조로 확인 문제·퀴즈·checklist로 증거를 남긴다.

## 표지 3안 비교 (실제 HTML 제작 → 1920×1080 캡처 비교 → 1안 채택)

라우터 후보 diagram(5.174)·orbit(5.159)·mosaic(4.777) 3종을 각각 제작해 비교:

| 안 | 구성 | 판정 |
|---|---|---|
| 1안 | **diagram** — 자물쇠 중심 + 세 단계(모으기·잠그기·지우기)를 잇는 흐름 도식 | ✅ 채택 — 반복 틀 '최소한만·잠가 두고·지우기'가 표지에서 이미 읽힘. 2초 테스트에서 주제+구조 동시 전달 |
| 2안 | orbit — 중심 열쇠 아이콘 + 궤도 잠금·문서·눈 아이콘 | 폐기 — 장식적이나 정보 구조 없음, '보호' 추상 상징에 그침 |
| 3안 | mosaic — 핵심어 타일 6개(개인정보·고유식별·잠금·파기·72시간·습관) 격자 | 폐기 — 키워드 나열이라 위계가 평탄, talk 덱 첫인상으로 약함 |

- 채택 근거: talk 덱의 표지는 '오늘 뭘 가져가는지'를 청중에게 미리 보여주는 약속 — diagram안이 반복 틀 3단을 시각화해 유일하게 그 역할을 함. graphite 테마의 어두운 배경에 얇은 선 도식이 잘 어울림.
- 비교 캡처: `qa/cover-compare/` 3장 보관, 폐기 2안은 src 미보관.
