인수인계 핵심 포인트

단일 관문

모든 외부 호출은 API GW 경로다. 우회 직접 호출은 인증·감사 구멍.

인증 경계

SSO 검증은 GW→인증 경로에서만. 443 외 인바운드는 없다.

대외 창구

외부기관 연동(IF-03)은 업무 API가 단일 창구다.

인수인계 포인트 — 모든 외부 호출은 API GW에서 시작·종료한다. GW를 우회하는 직접 호출 경로가 생기면 인증·감사 구멍이 되므로 신규 연동은 반드시 GW 경로로 등록한다.

P0 종합시스템 개요 장. 응답선 kind=r(점선+open 화살촉)이 라우팅 실선과 방향 쌍을 이루고, 내부망은 kind=member 면색 띠(소속), 왼쪽 주황 점선이 between 경계선(신뢰 경계)이다 — 소속과 신뢰가 분리됐다. 외부기관은 내부망 존 바깥 오른쪽에 배치된다(hint 간선으로 랭크 분리 — 망 경계 왜곡 방지). 1단계 존·경계, 2단계 노드, 3단계 연결.
