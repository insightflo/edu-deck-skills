인수인계 포인트

모든 외부 호출은 API GW에서 시작·종료한다. GW를 우회하는 직접 호출 경로가 생기면 인증·감사 구멍이 되므로 신규 연동은 반드시 GW 경로로 등록한다.

P0 종합시스템 개요 장 — 블루프린트 개편 시연. 외부 접속·DMZ 접근계층·내부 업무계층 3권역을 솔리드 헤더 존으로 나누고, 내부 업무계층은 GW·인증/서비스/데이터 하위존, 데이터는 저장 손자존까지 3단계 중첩. GW→서비스·WEB→GW 연결은 T-드롭 버스 3본으로 그려 점대점 엣지 남발 없이 고밀도 배선을 표현한다. API GW는 cluster 템플릿, 비동기 설비·DB는 rack-group, WEB은 HA 이중선. 1단계 존·경계, 2단계 노드, 3단계 연결.
