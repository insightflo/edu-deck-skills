SI 유형 A2 · 응용 아키텍처 — 3계층

3계층 — 온라인·배치 채널 분리로 장애 격리

인수인계 핵심 포인트

장애 격리

배치 WAS 장애가 온라인으로 번지지 않는 게 원칙.

세션 이중화

세션은 클러스터 공유 — 서버 1대 손실에도 로그인 유지.

배치 창구

배치는 DB·파일에만 붙는다. 온라인 테이블 직접 UPDATE 금지.

인수인계 포인트 — 온라인과 배치 채널이 WAS부터 갈라진다. 배치 지연·장애가 온라인 응답으로 번지지 않는 게 이 구성의 존재 이유다.

P0 응용 아키텍처. 레이어드 패턴(rankdir=TB)의 SI 변형 — 층을 표현(WEB)/응용(WAS)/데이터(DB)로 잡고, 온라인 WAS와 배치 WAS를 같은 층에 나란히 두되 연결선 종류(실선 동기 vs 점선 보조)로 계통을 구분한다. 세션(공유 세션 저장소 — 데이터 계층 자산으로 표기) 클러스터는 응용층 내부 의존으로 표시. 1단계 층 띠, 2단계 노드, 3단계 의존선.
