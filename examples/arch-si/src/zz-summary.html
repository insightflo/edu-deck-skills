정리

인수인계 체크리스트 — 오늘 확인하고 넘어갈 6가지

호출 경로

외부 호출이 전부 API GW를 거치는지 우회 경로 짚어 확인한다

동기·비동기

단말 응답 필요 여부로 갈린다 — 배치성 작업의 동기 편입 여부 확인

IF 대장

IF 번호·프로토콜·주기 3토큰으로 연동 목록을 전수 대조한다

망 경계

DMZ 3단 포트(443·8080·1521) 외 인바운드가 없는지 확인한다

이중화

본사·센터 전용회선과 백업 VPN, DR 승격 순서를 재확인한다

전환 범위

제거되는 외부 EAI의 업체·철회 일정이 이행 계획서에 있는지 본다

이 체크리스트는 교육용 예시 덱의 정리 장이다 — 실제 인수인계에는 프로젝트 구성도·IF 대장·이행 계획서 원본을 기준으로 같은 항목을 채운다.

정리 장. 여섯 항목은 앞 11장의 인수인계 포인트를 관점별로 한 줄씩 압축한 것이다. 항목을 하나씩 눌러 가며 학습자가 각 장의 어떤 근거에서 나온 확인 문항인지 되짚게 한다. 예를 들어 '망 경계'는 C1 DMZ 논리도의 3단 포트 격리에서, '이중화'는 C2 물리 회선과 C3 DR 승격 순서에서 나온다. 마지막에 이 덱이 가상 예시임을 다시 일러두고, 실제 프로젝트 문서로 같은 체크를 반복하도록 안내한다.
