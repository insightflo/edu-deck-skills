내부·외부 연계 구성 — IF ID·프로토콜·주기

읽는 법 — 실선: 동기 호출 · 점선+빈 화살촉: 응답 · 회색 보조: 비동기·배치 · 라벨: IF ID·프로토콜·주기

P0 연계 아키텍처. 허브(EAI) 매개 패턴으로 IF 번호·프로토콜·주기를 일관된 3토큰 라벨에 싣고 동기/비동기는 선 종류로 구분한다. 1단계 존·경계, 2단계 시스템(온라인 허브=청색, 내부 기간계=기본, 대외 기관=주황), 3단계 IF-01 대내 동기 호출·응답, 4단계 IF-02·IF-04 내부 배치 연계, 5단계 IF-03 대외 실시간 연계.
