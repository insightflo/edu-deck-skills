SI 유형 A3 · 연계 아키텍처 — 허브 패턴

연계 허브 — IF ID·프로토콜·주기를 한 곳에서 통제

인수인계 포인트 — 신규 연동은 허브 없이 직접 붙이지 않는다. IF 등록 후 허브 경로로만 낸다.

P0 연계 아키텍처. 허브(EAI) 매개 패턴으로 IF 번호·프로토콜·주기를 일관된 3토큰 라벨에 싣고 동기/비동기는 선 종류로 구분한다. 외부기관은 내부망 존 바깥 아래 대외 영역에 별도 존으로 분리된다. 1단계 존·경계, 2단계 시스템(온라인 허브=청색, 내부 기간계=기본, 대외 기관=주황), 3단계 IF-01 대내 동기 호출·응답, 4단계 IF-02·IF-04 내부 배치 연계, 5단계 IF-03 대외 실시간 연계.
