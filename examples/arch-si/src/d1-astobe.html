SI 유형 D1 · 변경 대조 (자체 저작 문법 · 위치는 모델이 고정)

차세대 전환 — As-Is → To-Be

읽는 법 — 같은 자리 = 같은 시스템 · 주황 = 신규 · 청색 = 변경 후 모습 · 회색 취소선 = 제거(전환 후 없음) · 1~4단계 = 유지 → 제거 → 신규 → 변경

이 장은 구성 변화 대조다(업무 절차가 아니다 — 절차 화살표는 쓰지 않는다). 1단계에 As-Is 전체가 서고, 2단계에 제거되는 외부 EAI가 흐려지며 취소선이 그어진다. 3단계에 신규 시스템(모바일 앱·WAS-2·DB-부·백업 볼트·모니터링)이 주황으로 등장하고, 4단계에 변경 대상(단일 WAS→WAS-1·야간 배치→스케줄러·파일서버→오브젝트 스토리지)이 청색으로 교체된다. 위치는 모델이 열·행으로 고정하므로 전환 전후에 같은 시스템이 같은 자리에 남는다 — dagre 같은 자동 배치는 노드 집합이 바뀌면 좌표가 흔들려 이 성질을 보장하지 못한다.
