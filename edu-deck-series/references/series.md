# series.md: 편 나누기 · 허브 유형 · series.json 양식 · 진도와 자습

edu-deck-series 의 시리즈 고유 규칙. 편 하나를 만드는 규칙(조사·구성·조각·문장)은 edu-deck-solo 의 문서(`<base>/references/`)를 그대로 따른다.

## 1. 편 나누기 기준

- **기본 뼈대**: 기초편 1개 + 심화편 2~4개. 전체 3~5편, 편당 10~16장(기초편은 12~16장, 심화편은 10~12장).
- **기초편**: 전체 그림을 한 번 훑는 편. 큰 개념·써볼 자리·조심할 일·익숙해지는 길을 선택한 주흐름에 맞게 다룬다. 심화편을 보기 전에 먼저 보는 편이라 목차에서 눈에 띈다(태그 `기초`).
- **심화편**: 한 주제를 깊게 다루는 편. 각 편은 스스로 완결된 학습 경험(목표·맥락·활동·확인 문제·성과 확인·마무리)이어야 하고, 기초편을 봤다는 가정 위에서 깊이만 올린다. 새 편에 별도 표지·순서 장을 강제하지 않는다.
- 나누는 잣대는 하나만: **역할별**(직무별로 다른 편), **단계별**(초보→중급→활용), **주제별**(독립 주제 묶음). 섞어 쓰면 목차가 흐려진다. 하나를 정하고 구성안에 밝힌다.
- 편 제목은 12자 이내, 편 소개는 40자 이내(목차 카드·미리보기에 그대로 나간다).
- 편마다 확인 문제(check 장) 1개 이상. 다시 보기 대상은 **같은 편 안**의 장(data-review ↔ data-key).

## 2. 분량·순서 규칙

- **기본 legacy 편**: `<base>/references/composition.md`의 legacy 순서(표지 → 순서 → … → 확인 문제 → 마무리)와 아키타입을 따른다. 이 경로에서는 편마다 중심 아키타입을 달리할 수 있다(예: 기초편=compare·mapping, 심화편=build-up·sequence).
- **팩 편(사용자가 요청·선택한 경우만)**: `<base>/references/resource-packs.md`의 주흐름과 배치 변형 계약을 따른다. 편별 학습 목적에 맞춰 순서를 정하고, 같은 디자인 안에서도 자료·활동에 맞는 독립 배치를 쓴다. 고정 표지 → 순서 구성을 요구하지 않는다.
- 32~60장(3~5편)이 기본. 80장이 넘으면 편을 더 나누거나 시리즈 자체를 나눈다.

## 3. 허브(목차) 유형 선택

| 유형 | 모양 | 어울릴 때 | 자동 추천 조건 |
|---|---|---|---|
| `map` 경로형 | 단계 묶음 줄 + 편 칸(진도 고리) | 단계가 있고 순서가 중요한 과정(입문→심화, 자격 과정) | 잣대가 **단계별**이거나 groups 를 표현할 수 있을 때 |
| `shelf` 책장형 | 책 등걸이 + 미리보기 패널 | 편이 독립적이고 골라 읽는 맛이 있는 묶음(주제별) | 잣대가 **주제별**, 편 2~4개 |
| `list` 목록형 | 표(편·제목·소개·분량·진도) | 편이 많거나(5+) 정보 전달이 우선, 콤플라이언스·목록 관리 | 편 5개 이상이거나 잣대가 **역할별** |

- 추천 규칙: 위 표의 조건으로 1개가 정해지면 그것을 구성안에 "추천"으로 적는다. 애매하거나 조건이 겹치면 후보 2개를 한 줄씩 비교해 사용자가 고르게 한다.
- 사용자가 유형을 정했으면 series.json `hub.type` 에 넣는다. 빌드 후 `--hub` 로 다른 유형을 잠깐 뽑아 비교해 볼 수 있다.

## 4. series.json 양식

```json
{
  "title": "사내 AI 교육",
  "eyebrow": "사내 AI 교육 시리즈",
  "updated": "2026-11-01",
  "intro": "기초편으로 큰 그림을 보고, 심화편 두 편으로 하나씩 깊게 들어갑니다.",
  "output": "사내-AI-교육-시리즈.html",
  "hub": { "type": "map", "groups": [ { "name": "먼저", "title": "기초 — 큰 그림 보기", "eps": [0] } ] },
  "glossary": [ { "term": "시리즈 진도", "plain": "…" } ],
  "episodes": [
    { "ep": 0, "folder": "ep0-기초", "label": "기초편", "tag": "기초",
      "title": "AI와 함께 일하기", "sub": "한 줄 소개", "color": "#1B2433", "met": "입구 · 전체 그림부터" }
  ]
}
```

- 필수: `title`, `episodes`(2편 이상). 편의 `folder` 는 작업 폴더 안 실제 폴더명.
- `ep`: 편 번호(0부터, 목차 순서와 같게). `label`: 목차·칩에 찍히는 편 이름("기초편", "1편"). `tag`: 기초/심화 구분(책장형 책장 구분선에 쓴다). `met`: 경로형 카드의 짧은 설명.
- `hub.groups`: 경로형에서만. 각 묶음의 `eps` 를 합치면 전체 편과 정확히 같아야 한다(조립기가 검사). 묶음이 필요 없으면 생략(한 줄로 나온다).
- `glossary`: 시리즈 공통 용어(선택). 편마다 deck.json 의 glossary 와 합쳐지고, 편 것에는 자동으로 그 편 태그가 붙는다.
- 편 `summary` 는 deck.json 의 것을 쓴다(편 항목에 직접 넣어 덮어쓸 수도 있다).

## 5. 진도와 자습 동작 (완성본에서 일어나는 일)

- **진도 저장**: 편을 열어 본 장 번호가 `localStorage` `edeck-ser-seen-<편>` 에, 마지막 장이 `edeck-ser-pos-<편>` 에 저장된다. 목차의 진도 고리·진도 막대·합계("N / M장")는 이 값으로 그려진다. 목차의 `기록 지우기`는 두 번 눌러 확인하며 진도와 확인 문제 기록을 모두 지우고 `edeck-reset` 이벤트로 자습 레이어에 알린다.
- **이어보기**: 한 편이라도 본 뒤 목차에서 그 편을 다시 열면 마지막으로 본 장부터 이어진다(끝 장까지 봤으면 처음부터). 책장형 미리보기의 "이어보기" 단추도 같은 규칙.
- **자습 레이어(solo 와 같은 스크립트)**: `shared/assets/js/study.js` 하나가 solo 덱과 시리즈 포털에서 함께 쓰인다(포털은 `#stage > .deck` 유무로 스스로 분기). S 자습 패널(편 라벨·장 위치·확인 문제 점수 줄), P 인쇄(편별 한 장 요약 = deck.json summary, 없으면 마무리·규칙 장 폴백 / 발표 대본), G 용어집(시리즈+편 합집합, 다른 편 용어는 그 편으로 이동). 목차 화면에서 S 는 안내만 나온다.
- **확인 문제**: 결과가 `edeck-ser-chk-<파일명>-<편>` 에 저장된다. 오답 → 해설 + "N장 다시 보기"(같은 편) → "돌아가기".
- **주소**: `#` = 목차, `#<편>-<장>` = 그 편 그 장(예: `#2-5`). 목차에서 숫자키로 편을 연다. Esc = 목차.
- **칩**: 각 편 슬라이드 오른쪽 위에 "〈편 라벨〉 · 목차(Esc)" 칩이 붙는다(조립기가 심는다). 누르면 목차로 돌아간다.
